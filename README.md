Smile Like You Meant to Freeze — one 186-character funny line a hopeless tech support agent says to a desperate customer whose job interview camera just froze mid-sentence: turn it off and on again, and if it comes back, smile like you meant to freeze.

## Run it

```sh
node main.ts
```

The program writes the text to `/output/entry.txt`.
